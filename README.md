# Scripts em Python: compilação de exemplos

Link para o curso: [Introdução ao Python 2.7 através de exemplos (2012)](https://stahe.github.io/pt-python2.7-mars-2012/)

---

## 📌 Descrição geral

Este projeto oferece uma compilação de scripts em Python que abrangem diversas áreas técnicas. Não se trata de um curso teórico, mas sim de uma **compilação de exemplos práticos** concebida para proporcionar uma introdução rápida.

### Tópicos abordados:

**Fundamentos** da linguagem Python.

* Gestão de bases de dados **MySQL**.

* Programação de redes TCP/IP

* Programação **web**.

* Arquiteturas **de três camadas** e programação baseada em **interfaces**.

---

## 🎯 Público-alvo

Este documento destina-se a programadores que já tenham experiência com:

* Linguagens de script (**Perl, PHP, VBScript**).
* Linguagens tipadas (**Java, C#**) e que desejem explorar a programação orientada a objetos em Python.

> [!IMPORTANTE]
> Este conteúdo **não é adequado** para principiantes absolutos em programação. Não pretende ensinar as «melhores práticas» absolutas; um programador experiente pode considerar que determinado código poderia ser otimizado.

## 📖 Como utilizar esta coleção

Para tirar o máximo partido deste repositório, é essencial a **leitura ativa**. Para cada script, encontrará:
* Código-fonte anotado.
* Uma reprodução da saída da consola.
* Explicações adicionais quando necessário.
